Most monitoring tools show you everything at once. Argus shows you the cluster you're responsible for, and nothing that isn't.

One pipeline,
node to answer.

  1. CollectAn OpenTelemetry Collector runs on every node as a DaemonSet and reads kubelet, node and pod metrics, plus Kubernetes events.
  2. IngestEach cluster sends OTLP to Argus. Clusters and nodes register themselves from the k8s.cluster.name attribute. No manual inventory.
  3. Store and queryEverything lands in ClickHouse with 1-minute and 1-hour rollups, so a week of data answers as fast as the last five minutes.

Alerts that
remember the fix.

  1. It firesThreshold rules run directly against your stored metrics and logs. Uptime checks raise their own alerts when an endpoint fails.
  2. It remembersWhen the same alert comes back, the notes from how it was resolved last time are right there on the alert.
  3. It learnsResolve it with a note, and the next person on call starts where you finished. Silence noisy alerts by fingerprint, title or severity.

Many clusters.
One at a time.

Connect as many clusters as you run. Every page in Argus (metrics, logs, traces, pods and alerts) is scoped to the cluster you pick, and access is granted per cluster, so each team sees what it owns.

  • Per-cluster accessRole-based access with cluster-level permissions.
  • Self-registeringNew clusters and nodes appear as soon as they send data.
  • Uptime built inSynthetic HTTP checks with expected status and response time.

Built on standards
you already trust.

OpenTelemetry

Standard OTLP over gRPC or HTTP. Bring the collectors and SDKs you already use.

ClickHouse

One columnar store for metrics, logs, traces and alerts. Fast to query, cheap to keep.

Your infrastructure

Docker Compose for a laptop, Helm charts for Kubernetes. No vendor in the data path.

Running in minutes.

Try it locally
docker compose up -d
# Dashboard: http://localhost:3000
Install on Kubernetes
helm install argus ./helm-chart/argus \
  --namespace argus --create-namespace \
  --set clickhouse.password=<password> \
  --set backend.jwtSecret=<secret>
Connect a cluster
# first set ARGUS_OTLP_ENDPOINT
# and CLUSTER_NAME in the manifests
kubectl apply -f otel-collector/kubernetes/
